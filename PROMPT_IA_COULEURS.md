# Prompt pour IA - Palette de couleurs DiscoverSenegal

Copiez-collez ce texte à l'IA qui va créer votre site vitrine :

---

**INSTRUCTIONS POUR LE SITE VITRINE DISCOVERSENEGAL - PALETTE DE COULEURS**

Je souhaite créer un site vitrine/communication/blog/avancement pour DiscoverSenegal qui utilise EXACTEMENT les mêmes couleurs que l'application principale. Voici la palette de couleurs complète à utiliser :

## COULEUR DE MARQUE PRINCIPALE : ORANGE

L'orange est la couleur signature de DiscoverSenegal. Utilisez-la pour :
- Tous les boutons d'action principaux (call-to-action)
- Le logo et le nom "DiscoverSenegal"
- Les éléments interactifs importants
- Les sections mises en évidence
- Les états hover des boutons

**Codes couleur Orange :**
- Orange-600 (Principal) : `#EA580C` - Pour boutons, logo, textes d'accent
- Orange-700 (Hover) : `#C2410C` - Pour états hover
- Orange-100 (Arrière-plan subtil) : `#FFEDD5` - Pour arrière-plans d'icônes, sections en évidence
- Orange-50 (Dégradé léger) : `#FFF7ED` - Pour dégradés de fond (ex: `bg-gradient-to-b from-orange-50 to-white`)

## SYSTÈME DE COULEURS PRINCIPAL

**Couleur Primaire (Primary) :**
- `#0F172A` (bleu très foncé, presque noir) - Pour boutons système par défaut
- Texte sur primary : `#F8FAFC` (blanc cassé)

**Couleur Secondaire (Secondary) :**
- `#F1F5F9` (gris très clair, bleuté) - Pour arrière-plans secondaires
- Texte sur secondary : `#0F172A` (très foncé)

**Couleur Destructive (Erreurs/Actions dangereuses) :**
- `#EF4444` (rouge vif) - Pour boutons de suppression, erreurs

**Fond et Texte :**
- Fond principal : `#FFFFFF` (blanc pur)
- Texte principal : `#020617` (presque noir)
- Texte secondaire : `#64748B` (gris moyen)
- Bordures : `#E2E8F0` (gris clair)

## COULEURS COMPLÉMENTAIRES

**Gris :**
- Gray-900 : `#111827` - Footer, textes très foncés
- Gray-600 : `#4B5563` - Textes secondaires
- Gray-50 : `#F9FAFB` - Arrière-plans légers

**Couleurs d'accent (pour varier les sections) :**
- Green-600 : `#16A34A` / Green-100 : `#DCFCE7`
- Blue-600 : `#2563EB` / Blue-100 : `#DBEAFE`
- Red-600 : `#DC2626` / Red-100 : `#FEE2E2`

## BORDER RADIUS
- Utiliser : `0.5rem` (8px) pour tous les éléments arrondis

## POLICE
- Famille : 'Inter', system-ui, Avenir, Helvetica, Arial, sans-serif

## RÈGLES D'UTILISATION

1. **Hiérarchie des boutons :**
   - Boutons principaux : Orange-600 (`#EA580C`) avec texte blanc
   - Boutons secondaires : Primary (`#0F172A`) ou variante outline
   - Boutons destructifs : Rouge (`#EF4444`)

2. **Sections de page :**
   - Hero section : Dégradé `from-orange-50 to-white` (`#FFF7ED` vers `#FFFFFF`)
   - Sections en évidence : Fond orange-600 (`#EA580C`) avec texte blanc
   - Sections standard : Fond blanc (`#FFFFFF`)
   - Sections secondaires : Fond gray-50 (`#F9FAFB`)
   - Footer : Fond gray-900 (`#111827`) avec texte blanc/gris clair

3. **Navigation active :**
   - Liens actifs : Fond orange-100 (`#FFEDD5`) avec texte orange-700 (`#C2410C`)

4. **Focus et états interactifs :**
   - Hover sur éléments orange : Orange-700 (`#C2410C`)
   - Focus rings : `#020617` (très foncé)

## RÉSUMÉ RAPIDE DES CODES HEX

```
PRINCIPAL :
Orange-600: #EA580C
Orange-700: #C2410C
Orange-100: #FFEDD5
Orange-50:  #FFF7ED

SYSTÈME :
Primary:       #0F172A
Secondary:     #F1F5F9
Background:    #FFFFFF
Foreground:    #020617
Destructive:   #EF4444
Border:        #E2E8F0
Muted text:    #64748B

UTILITAIRES :
Gray-900:      #111827
Gray-600:      #4B5563
Gray-50:       #F9FAFB
```

**IMPORTANT :** L'orange (`#EA580C`) doit être la couleur dominante pour tous les éléments de marque et call-to-action. Le reste doit suivre ce système de couleurs pour maintenir la cohérence avec l'application principale DiscoverSenegal.
